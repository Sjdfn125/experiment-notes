# 实验笔记开发文档

## 数据流与代码结构

表格是数据来源。输入修改后更新内存中的实验记录并保存，图表在下一次浏览器绘制时读取当前记录。CSV 读取完整表格，PNG 读取应用了当前图表设置的画布。

| 文件 | 职责 |
| --- | --- |
| `index.html`、`src/styles.css` | 页面结构、表格、图表面板及窄屏布局 |
| `src/records.ts` | 记录、列和行的结构、坐标轴匹配、存储读取校验与 CSV 序列化 |
| `src/charts.ts` | 将所选列的数据转换为 ECharts 图表配置 |
| `src/statistics.ts`、`src/analysis-panel.ts` | 统计量、线性拟合、经验累积分布与均值检验 |
| `src/merge.ts` | 按记录、行、列和单元格合并其他标签页的改动 |
| `src/main.ts` | 表格和记录交互、本地保存、图表更新与文件下载 |
| `tests/workbench.spec.ts` | 主要功能的端到端验收 |

每份记录包含名称、列、行和当前图表配置。列使用稳定 ID，行内数据及坐标轴都按该 ID 引用，因此修改列名能保留数据和轴选择。删除列或更换图表类型后，应用会重新查找符合要求的坐标轴。删除带数据的行或列需要确认。

工作区保存在 `experiment-notes/workspace/v1`。若存储内容无法读取，应用保留原内容，并允许用户在当前会话临时编辑及导出。持久化范围是当前浏览器配置和访问地址。

## 绘图与导出规则

- 折线图的数值 X 轴按数值排序。使用文本 X 轴的折线图和柱状图按表格顺序显示。柱状图的每一行对应一根柱。
- 散点图使用两列数值。数值列接受有限的十进制数，包括负数、零、小数和科学计数法。缺少有效坐标的行跳过绘制，表格和 CSV 保留原始输入。
- CSV 使用 UTF-8 BOM 和 CRLF。逗号、双引号和换行按 CSV 规则转义，可能被电子表格解释为公式的文本前置单引号。PNG 使用当前图表画布，以两倍像素比导出。

## 验收

### 统计方法

- 分析列使用全部有效的有限数值。样本均值估计期望。经验方差使用分母 n，样本方差使用 n−1。只有一个观测时，样本方差显示为缺失。
- 经验累积分布在每个观测值处跳跃，跳跃高度为该值的频数除以有效样本数。它保留重复值的信息，无需预设分布族。
- 散点图用成对有效的 X、Y 拟合带截距的最小二乘直线。X 全部相同时无法拟合斜率，Y 恒定时 R² 无定义。斜率使用纵轴单位除以横轴单位。
- 双侧单样本 t 检验使用 t = (样本均值 − 假设均值) / (样本标准差 / √n)，自由度为 n−1。双侧 p 值通过 jStat 的正则化不完全 Beta 函数计算。显著性水平可选 0.01、0.05 和 0.10。样本方差为零或有效样本不足两个时显示原因。水温示例是同一对象随时间变化的模拟数据，适合演示趋势。均值推断应选独立观测，小样本还要求总体近似正态。[NIST 均值检验说明](https://itl.nist.gov/div898/handbook/prc/section2/prc22.htm)

### 多标签页保存

浏览器以 Web Locks 串行处理同一来源上的写入。每次在锁内读取最新存储，比较本页上一次看到的版本、本页编辑结果和最新存储。不同字段可合并，同一字段被两边修改时由用户选择。页面保留自己的编辑视图，刷新可读到其他页的新值。无法使用安全写入机制时，状态栏提示导出。旧版数据沿用原存储键，新增的统计选项按需保存。

### 测试命令

```bash
npm run build
npm test
```

Windows 上自动测试使用 Microsoft Edge。其他平台可安装 Playwright Chromium，再运行测试。

```bash
PLAYWRIGHT_BROWSERS_PATH="$PWD/.work/pw-browsers" npx playwright install chromium
npm test
```

自动测试覆盖手动录入、无效数字、三种图表、刷新恢复、实际下载的 CSV 内容和 PNG 像素、记录切换、行列增删、窄屏和损坏存储保护。手动验收时可用以下流程录制演示。

1. 在空白记录中手动录入三组时间与测量值，展示折线图如何随数据更新。
2. 载入模拟水温数据，切换柱状图和散点图，修改图表标题、颜色。
3. 下载 CSV 和 PNG，打开文件查看实际结果。
4. 刷新页面，确认当前记录、表格和图表配置仍在。

统计与并发回归位于 `tests/analysis.spec.ts`。其中使用已知样本检验方差、累积分布阶跃、斜率和双侧 p 值，并检查趋势线在导出 PNG 中的实际像素。两个独立标签页的用例覆盖不同行编辑和同一单元格两种冲突选择。
